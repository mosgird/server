# Contributing to Mosgird server

The contribution process for this repository is the same as for the protocol repository. See [CONTRIBUTING.md](https://github.com/mosgird/protocols/blob/main/CONTRIBUTING.md).

This repository adds one requirement: the `contribution-policy` check must pass before a pull request can merge.

Implementation details for server belong in this repository, in its own documentation. Protocol behavior belongs in the protocol repository.
